# STRATE_GLOSSARY.md
### Glossaire des termes transversaux de STRATE
Dernière mise à jour : —

> Ce document définit les termes utilisés à travers plusieurs applications STRATE, pour garantir qu'un même mot ait toujours le même sens, peu importe le module.
>
> Ce n'est PAS le Domain Model : le Domain Model (`STRATE_DOMAIN_MODEL.md`) décrit les entités métier en détail (attributs, relations, règles, cycle de vie). Ce Glossaire donne une définition courte et renvoie au Domain Model quand le terme y est développé en profondeur.

Format par terme :
```
Terme :
Définition courte :
Application(s) concernée(s) :
Voir aussi (Domain Model) : oui/non, section si applicable
```
